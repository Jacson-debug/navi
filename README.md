# Наві — навігація без GPS (прототип 0.7)

Карта для авто, яка веде без супутників: гіроскоп + акселерометр телефону, прив'язка до графа доріг,
захист від підміни координат, АЗС із ручними позначками «працює / не працює». Усе працює офлайн,
без підключень до авто.

## Що в папці

| Шлях | Що це |
|---|---|
| `index.html`, `js/app.js` | застосунок (PWA): карта, кнопки, АЗС, маршрут, демо |
| `js/engine.js` | рушій позиціонування: датчики → фільтр по графу → позиція |
| `js/motion.js` | обробка гіроскопа/акселерометра: осі авто, швидкість, повороти, зупинки |
| `js/filter.js` | фільтр частинок, прив'язаний до доріг (map matching без GPS) |
| `js/graph.js`, `js/astar.js` | граф доріг, пошук маршруту (найшвидший з урахуванням пробок), підказки поворотів |
| `js/buildings.js`, `js/voice.js` | будинки/адреси/під'їзди (buildings.bin), пошук адреси; голосові підказки |
| `js/traffic.js` | «пам'ять пробок»: типова швидкість на кожній ділянці за годинами, офлайн |
| `js/testcity.js`, `js/simulator.js` | тестове місто та симулятор поїздки для перевірки алгоритму |
| `tools/sim.mjs` | консольна перевірка точності: `node tools/sim.mjs 12` |
| `tools/prepare_osm.py` | підготовка справжньої карти Києва й області з OpenStreetMap |
| `sw.js`, `manifest.webmanifest`, `icons/` | офлайн-кеш та встановлення на головний екран |
| `data/` | сюди лягають `graph.json` і `fuel.json` після підготовки карти |

## Крок 1. Подивитись демо на комп'ютері

У папці проєкту:

```
python -m http.server 8080
```

Відкрити `http://localhost:8080`. Поки немає `data/graph.bin`, застосунок працює на тестовому місті.
Алгоритм перевіряється не в застосунку, а консольним прогоном: `node tools/sim.mjs 12`.

## Крок 2. Справжня карта (Київ + область)

Потрібен Python 3.9+ та інтернет. Один раз:

```
pip install osmium
python tools/prepare_osm.py
```

Скрипт сам завантажить `ukraine-latest.osm.pbf` (~1 ГБ) і за кілька хвилин створить
`data/graph.bin` (дороги), `data/buildings.bin` (будинки, адреси, під'їзди) та `data/fuel.json` (усі АЗС з OSM). Потрібно 3–5 ГБ вільної ОЗП; якщо мало —
`python tools/prepare_osm.py --disk-index`. Лише Київ (швидше, менше):
`python tools/prepare_osm.py --bbox 50.2,30.2,50.65,30.95 --name Київ`.

## Крок 3. Поставити на iPhone

Для датчиків руху iOS вимагає HTTPS, тому застосунок треба викласти на хостинг. Найпростіше — GitHub Pages
(безкоштовно): створити репозиторій, завантажити туди вміст цієї папки, у Settings → Pages увімкнути
публікацію з гілки `main`. Далі на iPhone у Safari відкрити адресу, натиснути «Поділитись» →
**«На Початковий екран»**. Після першого відкриття застосунок і карта зберігаються на телефоні та
працюють без інтернету.

У авто: телефон у кріпленні → **Датчики** → дозволити рух і геолокацію → кілька секунд постояти, потім
рушати. Якщо GPS немає з самого початку — **Я тут** і торкнутись перехрестя, де ви стоїте.
Якщо на карті авто повертає не в той бік — «⋯» → «Повороти дзеркальні».

## Як це працює (коротко)

1. Телефон у кріпленні: за гравітацією визначається «вгору», за першим розгоном — «вперед».
2. Гіроскоп дає повороти, акселерометр — швидкість (обнуляється на кожній зупинці, уточнюється на
   поворотах через доцентрове прискорення, калібрується за GPS, поки він є).
3. Сотні гіпотез-«частинок» рухаються по графу доріг; на кожному перехресті обирається ребро, що
   узгоджується з гіроскопом. Різкий поворот посеред прямої ділянки означає, що авто вже на перехресті, —
   гіпотеза «прищіпається» до нього. Так геометрія вулиць постійно виправляє дрейф датчиків.
4. GPS-фікс, якого авто фізично не могло досягти (стрибок), ігнорується — це захист від підміни.

Точність на симуляції (тестове місто, телефон під довільним кутом, 2–3 км без GPS):
медіана похибки 30–45 м, у частині поїздок — тимчасова помилка «на квартал» до наступного повороту.
Реальні вулиці нерегулярніші за тестову сітку, що алгоритму лише на руку; справжню точність покажуть
записи поїздок («⋯» → «Запис датчиків»).

## Звідки береться позиція

Застосунок пробує джерела в такому порядку, і не чекає на супутники:

1. **Мережа зв'язку (вежі та Wi-Fi).** Одразу після «Датчики» запитується груба позиція
   (`enableHighAccuracy: false`). iOS не дає застосунку сирі вежі, але сама визначає по них
   місце й повертає його з великим радіусом похибки: у місті зазвичай ±50–200 м (поруч є Wi-Fi),
   за містом ±500–3000 м (лише вежі). РЕБ глушить супутники, а не мобільний зв'язок, тож це
   джерело лишається робочим. Позиція з'являється за секунду-дві, без жодних дій.
2. **Супутники**, коли сигнал є: уточнюють позицію до кількох метрів.
3. **Датчики руху + карта доріг** звужують грубе коло під час їзди: кожен поворот відсіює
   частину гіпотез. Мережеву позицію перепитуємо кожні 25 с — вона утримує від розбігання.
4. **Ручний старт** («Я тут») — коли немає ні супутників, ні мережі.

Мережевий фікс також працює як **перевірка на підміну**: РЕБ може підсунути «точні» координати,
але вежі зв'язку підмінити важче. Якщо супутниковий фікс далеко за межами мережевого кола,
він відхиляється, а в шапці видно «ПІДМІНА (не збігається з мережею)».

Точність на симуляції (тестове місто — правильна сітка, найгірший випадок для прив'язки до доріг):

| Сценарій | Медіана похибки |
|---|---|
| GPS спочатку, далі РЕБ | 31 м |
| РЕБ у місті, лише мережа ±150 м | 134 м |
| РЕБ за містом, лише вежі ±800 м | 285 м |
| Ні GPS, ні мережі, ручний старт | 100 м |

## Інтерфейс

Чотири кнопки: **Старт** (датчики й позиція), **Пошук**, **Я тут**, **⋯**.

«Пошук» — один список для всього: адреси, вулиці та АЗС разом, вкладки «Усе / Адреси / АЗС».
Порожній запит показує нещодавні цілі та найближчі АЗС. У кожному рядку: 👁 показати на карті,
«Маршрут» — прокласти шлях; для АЗС ще дві позначки «є / нема» пального.

Під рядком стану видно **де ви зараз** — найближчий будинок з номером або назва вулиці.
Карту можна вільно тягати й масштабувати; коли вона від'їхала від вас, унизу праворуч
з'являється кнопка «⌖ До себе».

Дрібні вулиці ховаються при віддаленні, **але дорога під вами видима завжди** і підсвічена,
інакше неможливо зрозуміти, де ви. АЗС показуються при наближенні (інакше вони заливають
карту сотнями позначок); ті, які ви позначили, видно завжди.

## Масштаб і назви місцевостей

Карту можна віддалити до всієї Київської області (понад 300 км в екран) — на дрібному масштабі
лишаються самі магістралі, інакше це мільйон ліній і гальмування. Навколо вашої позиції завжди
світиться кругла «лінза» з усіма дорогами, щоб було видно, по чому ви їдете.

Назви міст, сіл і районів беруться з `data/places.json`. Якщо файлу немає, карта працює без підписів;
щоб вони з'явилися, треба один раз перезапустити `py tools\prepare_osm.py` — він тепер збирає і їх.
**Після перезапуску комітьте лише `data/places.json`**: `graph.bin` і `buildings.bin` перезапишуться
тими самими даними, і щоразу додавати їх у репозиторій означає роздувати його на 31 МБ.

## Адреси, будинки, під'їзди, голос

«Адреса» → «Хрещатик 22» → «→» будує маршрут до будинку. При наближенні на карті з'являються контури
будинків, ближче — номери, ще ближче — під'їзди (помаранчеві точки з номером, де він є в OSM). Під'їзди
в OpenStreetMap позначені лише для частини будинків Києва і майже відсутні в області.
Голосові підказки («через 200 метрів праворуч на Хрещатик») — вбудований синтезатор iOS, офлайн;
вмикаються в «⋯». Українського голосу може не бути на телефоні — тоді iOS → Параметри → Універсальний
доступ → Озвучування вмісту → Голоси → Українська.

## Пробки (офлайн, з пам'яті поїздок)

Застосунок запам'ятовує, з якою середньою швидкістю ви реально проїжджали кожну ділянку в різні години
(будні та вихідні окремо). На карті це кольорова смужка вздовж дороги у бік руху: зелена — вільно,
жовта — повільно, червона — стоїмо. Маршрут будується як найшвидший за цими даними, а не найкоротший.
Це типова картина за вашими поїздками, а не стан доріг прямо зараз: ДТП чи перекриття, що сталося
10 хвилин тому, вона не покаже. Для живих пробок потрібен інтернет (TomTom/Google) — це наступний етап.
Дані лежать на телефоні; «⋯» → «Наїздити історію (демо)» показує, як це виглядає на тестовому місті.

## Обмеження прототипу

- PWA на iOS не працює у фоні: екран має бути увімкнений (застосунок сам не дає йому згаснути).
- Вежі зв'язку та Wi-Fi на iPhone недоступні — прив'язка лише до доріг і ручна.
- Статус АЗС — лише ваші власні позначки, зберігаються на телефоні.
